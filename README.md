# FinSight AI

Privacy-first personal finance intelligence built with Next.js and TypeScript.

## Features
- Multi-currency transactions: PKR, USD, EUR, GBP, AED, SAR
- Dashboard, transactions, budgets, goals and analytics
- Local financial intelligence and AI-style advisor
- Automatic expense categorization
- Financial health score
- Spending concentration/anomaly signals
- Savings goals and progress tracking
- CSV and JSON import/export
- Monthly reports through analytics
- Responsive SaaS-style UI
- Dark/light mode
- No account, database, API key or paid AI service required

## Run
Requirements: Node.js 20.9+ and npm.

```bash
git clone <your-repository-url>
cd fin-sight-ai/frontend
npm install
npm run dev
```

Open http://localhost:3000.

## Vercel
- Framework: Next.js
- Root Directory: `frontend`
- Build Command: `npm run build`
- Output Directory: leave default/empty
- No environment variables required.

## Privacy
Finance data stays in browser localStorage. No third-party AI API receives transaction data.

## Disclaimer
FinSight AI provides educational budgeting insights, not professional financial, tax, investment or legal advice.
